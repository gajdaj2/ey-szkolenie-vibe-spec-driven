# Asystent dokumentacji — instrukcje dla agentów AI

Prototyp asystenta dokumentacji wewnętrznej (FastAPI + LLM), Python 3.12+. Kod w `app/`, testy w `tests/`.
Sekrety tylko z `os.environ` (plik `.env`), nigdy w kodzie; w `data/` wyłącznie dane syntetyczne.
